# Photo Studio Generator

**An interactive, portable AI photo-editing prompt builder.**  
by **enviee-labs**

Photo Studio Generator is a standalone, single-file AI skill that helps anyone create detailed, copy-ready editing prompts in chat, without a plugin or photo-editing integration.

## Features

- Interactive in-chat configuration (when supported; conversational fallback otherwise)
- 10 editing presets and 10 optional color-grading styles
- Enhancement, realistic skin retouch, lighting, aspect ratio and background controls
- Multi-photo collage prompting with individual enhancement before assembly by default
- Identity, distinctive facial features and original skin-tone protection
- One complete portable prompt as output — **does not edit images**

## Quick start

1. Open [SKILL.md](SKILL.md) and copy the instructions into an AI assistant that supports custom skills or instructions.
2. Ask: `Open Photo Studio Generator`.
3. Choose your editing settings, then select **Generate Prompt**.
4. Copy the resulting full prompt into an image editor, attaching your original photo(s) there.

> Skill installation and interactive controls vary by platform. Where custom skills or controls are unavailable, paste the SKILL.md instructions into a conversation and use the conversational configuration fallback. A compatible image editing model/tool is needed to actually edit photos.
